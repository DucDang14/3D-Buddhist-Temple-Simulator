# Architecture

Online Pagoda is a browser-based 3D temple simulator.

## Planned technologies

- React: interface and component organization
- TypeScript: type checking
- Vite: development server and production builds
- React Three Fiber: render 3D scenes using React
- Drei: helpers for React Three Fiber

## Folder responsibilities

- src/scenes: assemble the temple environment
- src/player: character, movement, and camera
- src/interactions: incense, bowing, and bell behavior
- src/components/ui: menus, instructions, and prompts
- src/hooks: reusable React behavior
- src/styles: application styles
- public: models, audio, and textures

## Current status

Project folders and documentation files are created.
Application setup has not started.
